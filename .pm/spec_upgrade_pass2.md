# 第 2 輪修正（接續上一輪的模型改版，index.html 已有上一輪的修改，請在其基礎上改）

我用 headless Chrome 實測了：模型 29 個全部載入成功、沒有錯誤，風格方向對了。附圖第 1 張是現在的手機截圖，第 2 張是主角往北走 4 秒後的連續畫面（主角整個被樹淹沒看不到），其餘是參考圖。請修這些問題：

1. **狩獵空地（最重要）**：現在雪松密到遊玩區域也全是樹，主角走進森林就完全被遮住。參考圖是：道路北側有一大片「空地」雪地，熊在空地上走，只有零星幾棵可砍的樹；密林只在空地外圍形成邊界。請：
   - 在道路北側的熊活動區／可砍樹區留出大空地（半徑約 10–14 世界單位，依現在的地圖比例調整），空地內只保留可砍的樹（約 8–14 棵，分散），密林只放在空地外圍和地圖邊緣。
   - 主角或熊被樹遮住時要看得到：對靠近主角、且在主角與鏡頭之間的樹做淡出（例如那些實例縮小或改用半透明），或至少保證空地內不會遮擋。
   - 熊不能走進密林裡；限制在空地範圍。
2. **樹形**：雪松看起來太高太尖、太多白色。改成更矮胖圓潤（x/z 放大 ~1.25、y 縮小 ~0.85），大小差異小一點（0.9–1.3），讓藍色更明顯（樹材質顏色乘一點藍，例如 color #cfe6ff 或調整 emissive 讓藍更飽和；不要改 assets 內檔案）。
3. **主角和熊大一點**：主角放大約 1.3 倍，熊約主角的 1.5 倍大。主角要在畫面中一眼看到（綠色、綠光環）。
4. **客人顏色**：現在客人被染成橄欖綠、臉也變暗。參考圖客人是藍綠色（青色）連帽大衣。請改成只讓衣服變成青藍色、膚色保持：做法可以是 clone 該角色的 colormap 貼圖到 canvas，把非膚色（非橘/米色系）的像素 hue 改成青藍 (#3fb4d8 附近)，再做成新的 CanvasTexture 給客人用（一次產生、共用）。
5. **攤位更顯眼**：道路旁的販售攤位要像參考圖：木頭長桌（bench/workbench 組合）上擺肉，前面是白色虛線框放貨區，客人從攤位前排隊。現在攤位在遠景幾乎看不出來，放大一點並放在道路南側邊緣、隊伍的開頭處。
6. **右上資源面板**：再縮小約 25%，四行小膠囊（圖示 + 數字），像參考圖一樣不顯眼；音樂/暫停兩顆按鈕更小或移到面板下方縮成 28px。
7. **效能**：手機要順，所有樹/石頭盡量用 InstancedMesh，總 draw calls 盡量 < 250。
8. **測試掛鉤**：加 `window.__debug = { state(){ return { player:{x,z}, bears:[{x,z,alive}], trees:[{x,z,alive}] (只列可砍的樹), stack: 背包數量, coins, meat, wood, calls: renderer.info.render.calls, fps } } }` 方便我自動測試。另外告訴我 W/A/S/D 分別對應世界座標哪個方向（寫在程式註解裡即可，並在 __debug 加 `keys: {KeyW:[dx,dz],...}`）。

必須保留：搖桿、鍵盤、自動攻擊、熊、肉/木頭/金幣、頭頂疊物與 +N、解鎖區金幣飛入與彈出、升級、刀光/煙霧特效、`?autostart=1`、存檔、模型載入失敗的 fallback、`window.__models`。
