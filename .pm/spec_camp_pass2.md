## B. E3 自衛隊
## 兵營
- 警衛哨(id guardpost, 位置與價格見上方 A1)：survival-kit 的 tent / fence-fortified / signpost 組成，旁邊立一面旗（可用 holiday-kit festivus-pole 或幾何）。舊存檔若已超過該位置，也要讓它出現為下一個框。
- 解鎖後警衛哨前方常駐一個「招募框」（白色虛線框＋頭像/盾牌圖示＋價格）。主角站在框內：每 0.5 秒若金幣與肉足夠，就招募 1 人：花 $ (30 + 20×現有人數) 與 2 塊肉（肉從頭頂疊物飛進框）。上限 8 人（之後解鎖可再提高也可以）。
- 新隊員從隊伍裡的一位難民變裝而來（mini-characters 模型換成 character-soldier 或 recolor 成綠色制服＋紅臂章），彈出＋星芒。

## 隊員 AI（每人一個狀態機）
- follow：在主角身後 2–3 單位排成鬆散隊形跟隨。
- hunt：附近 7 單位內有活熊 → 走過去攻擊（每 0.8 秒造成 1 傷害，有揮擊動畫＋重用刀光），熊死時戰利品照舊掉落，並自動飛向主角疊物（主角滿了就留在地上）。
- build：當有解鎖框「付清」時，建築不直接彈出，而是進入施工：顯示鷹架/木框，最多 3 名空閒隊員走到框邊，揮槌（上下擺動手臂或整體小跳＋木屑粒子＋敲擊音效），建築從地面慢慢升起（約 3 秒，隊員越多越快；0 名隊員時主角自己 2.5 秒內完成，保持舊體驗），完成時才播 overshoot＋星芒。
- 自動擴建：有隊員時，若主角站在框內付錢，隊員同時趕來；付清前隊員在旁邊待命。
- 隊員穿過道路與熊區時不要卡住（簡單直線移動＋避開半徑即可），走路有彈跳、面向移動方向，有 blob 影子。
- 效能：最多 8 人，不要每幀 new 物件。

## 存檔
state.squad（人數）存進 localStorage；重新整理後隊員出現在警衛哨旁。

## 除錯
?debug=1 時 window.__po 增加 squad 陣列（x,z,mode）與 recruit() 函式（免費招 1 人，只供測試）。

## 驗收
無 console error；可以看到隊員跟著主角、打熊、去解鎖框施工、建築慢慢升起。

## 必須保留
右下搖桿、左下衝刺/升級、自動攻擊、頭頂疊物＋「+N」、刀光/雲朵、金幣拋物線、升級選單、相機 frustum ~29、moveSpeed 6.6、?autostart=1、?fresh=1、?debug_coins、?debug=1 的 window.__po（請加上 squad 與 recruit()，以及 nextZone 的 {id,x,z,cost}）。舊存檔相容。

## 測試
你的沙盒不能開 socket，所以無法開瀏覽器；請用 node 抽出 module script 做 node --check，並盡量用 node 寫小測試驗證純邏輯（清單順序、程序擴建座標不重疊、存檔遷移）。我會另外用瀏覽器驗證。
